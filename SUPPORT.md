# Getting help

- **Questions about using or deploying the project:** open a [discussion](https://github.com/xcapit/verifiable-policy-registry/discussions) or an issue with the *question* label.
- **Bugs and feature requests:** use the [issue templates](https://github.com/xcapit/verifiable-policy-registry/issues/new/choose).
- **Security problems:** do not open an issue, follow [SECURITY.md](SECURITY.md).
- **Conduct problems:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## A site is wrongly blocked at a school

This repository is not the place to report it. Use the link on the block page shown by the school network: it files an appeal with the institutions that govern that network's policy, and the decision is published on-chain (see [docs/GOVERNANCE.md](docs/GOVERNANCE.md)). Please never include names, photos or other details about students in an appeal or an issue.

## Institutions interested in a deployment

Ministries, connectivity programmes, municipalities or NGOs that want to run the registry for their own networks can contact the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md). The playbook for new deployments is planned for milestone M3 ([ROADMAP](docs/ROADMAP.md)).
