# ADR-0006: Scope limited to bounded networks such as schools

- Status: Accepted
- Date: 2026-11-09

## Context

Content filtering technology can be used to protect children, and it can also be used to restrict the information rights of whole populations.

## Decision

The project supports bounded networks with an accountable governor: schools first, then libraries, municipal Wi-Fi or NGO networks. It does not add features aimed at ISP-wide or national blocking, and pull requests that do so are declined.

## Consequences

Some potential users are out of scope. That is intended, and it is part of how the project does no harm by design.
